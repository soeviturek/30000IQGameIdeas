> 来源：群聊头脑风暴 → v1 → review.md → v2 → review2.md（复审）→ review3-monetization-pivot.md（商业模式定位变更）

## 一、核心结论（v3 定位）

1. **商业模式：买断制 + DLC**。不再有抽卡系统，角色通过**剧情推进/成就解锁**获得，付费点从"随机抽卡"变成"内容付费"（新角色、新关系线、新章节DLC）。
2. **玩法骨架不变**：局内秒境割草（实时操作，核心可玩性）+ 局外门派养成（推进解锁，长线内容）分层结构保留，且**优先级进一步提升**——买断制没有长线抽卡内容续命，局内玩法深度是玩家愿不愿意买单的唯一理由。
3. **新增：最多4人联机设计**（v2完全没涉及，见§四）。
4. **上瘾机制全面调整**：抽卡相关的"变率强化""社交裂变氪金驱动"整段替换为"局内Roguelite随机词条"和"合作向轻量分享"，见§三。
5. **v2 数值 bug 已处理**：抽卡保底公式（原 `0.006 + (pull_count-70)*0.06` 在88抽即溢出100%）**整节删除**，不再需要该设计。
6. **版号/合规提示保留但降权**：买断制单机游戏走Steam/主机分发基本不涉及抽卡类审批复杂性，若后续要上国内平台仍需评估版号，一句话提示即可，不再展开（详见§七）。
7. **v4新增：解决"联机×暧昧剧情如何共存"的结构性冲突**（review4提出，此前几轮从未被讨论），以及**DLC内容边界模糊**问题，见§四、§六。

## 二、核心玩法结构（局内/局外，与v2一致，优先级调整）

### 局内：秘境割草关卡（实时操作，游戏最核心卖点，优先级最高）
- 单局8-15分钟，自动攻击最近敌人，玩家走位躲避地面弹幕/Boss技能（对标吸血鬼幸存者/杀戮尖塔式流派构筑）。
- 击杀掉落"造化珠"，随机三选一升级法宝，法宝间存在组合进化——**这个"三选一随机词条"就是买断制下承接原"抽卡不确定性快感"的核心随机奖励钩子**，不依赖抽卡也能提供变率强化体验（见§三）。
- 章节式内容结构（对标杀戮尖塔的"周目"/"上升难度"设计），而非无限刷的赛季制。

**武器/技能基座 + 进化组合（优先级提升，建议尽快从7条扩到20+条）：**

| 基座法宝 | 基础效果 | 进化条件 | 进化后效果 |
|---|---|---|---|
| 惊鸿剑气 | 前方扇形范围伤害 | +符箓术满级 | 剑气化虹，360°环绕+击退 |

| 灵狐印 | 召唤灵宠自动索敌 | +饲育丹×3 | 九尾化身，灵宠×3+吸血 |
| 定风珠 | 减速范围敌人 | +冰魄玉 | 凝霜领域，持续冻结+范围扩大 |
| 蛊虫囊 | 中毒持续伤害 | +毒龙丹 | 万蛊噬心，中毒跨怪传染 |

- 弟子历练产出资源，种灵草炼丹，**角色通过剧情章节推进/成就达成解锁**（例如通关第X章解锁"收徒"剧情，自动获得该角色），不再是随机抽卡获取。
- 局外养成结果（根骨/悟性/福缘三维属性）影响局内初始强度，闭环保留。

## 三、上瘾/参与感机制设计（v3：移除抽卡驱动，替换为买断制适配版本）

### 1. 随机奖励钩子（原"变率强化"，去抽卡化）
- **局内三选一随机词条**是核心随机奖励来源：每次升级从3个随机法宝/词条中选1个，天然带来"这把出货了/没出货"的赌博式快感，且完全不涉及付费，是买断制下最合规也最有效的方案。
- 章节Boss掉落稀有词条书（永久解锁新词条池），给通关行为一个"开箱"式惊喜，替代原抽卡的"开箱感"。

### 2. 沉没成本钩子（适配买断制，去除赛季通行证）
- ~~赛季通行证~~（不适用于买断制，已删除）。
- 改为**章节/DLC发布节奏**：定期推出剧情DLC作为"内容更新期待感"，类似杀戮尖塔/死亡细胞的免费更新+付费DLC节奏。
- 图鉴/成就收集系统（法宝进化图鉴、角色关系图鉴全收集成就），驱动完成度驱动型玩家的长线目标。

### 3. 社交/传播机制（去除PVP氪金驱动，改为合作向+轻量分享）
- ~~排行榜赛季结算~~、~~门派战PVP驱动氪金~~（不适用无大DAU的买断制单机/联机游戏，已删除）。
- 改为**"晒角色养成/晒法宝流派"截图分享**：一键生成养成成果卡片，轻量传播，不绑定资源奖励（无需氪金驱动，纯分享驱动）。
- 4人联机的"组队开黑"本身就是强传播点（好友邀请一起联机闯秒境），比排行榜更适合这个产品形态。

### 4. 三层目标叠加（保留，去掉赛季相关表述）
- **单局目标**：本局击杀数、存活时间、连击评级。
- **周目/章节目标**：章节Boss通关、法宝图鉴收集进度。
- **长线目标**：全成就收集、DLC剧情线完整体验。

## 四、多人联机设计（v3新增，回应review3 §三三个问题）

1. **联机形式**：建议采用"局内共享同屏联机"（4人同屏对抗同一波怪，对标暗黑地牢/元气骑士式联机割草），而非各自独立局外+仅Boss联机——因为局内割草是核心卖点，联机的爽感应该发生在这里，能最大化"组队开黑"的传播价值。局外门派养成建议**各自独立**（每个玩家有自己的门派进度），避免联机强绑定造成的排期/进度不同步问题。
2. **掉落分配规则**：建议采用"独立结算"（每人各自获得法宝/资源掉落，不共享战利品），减少4人联机中的资源竞争摩擦，保持"各自变强、共同作战"的协作感而非零和竞争。
3. **联机专属内容**：建议设计需要分工站位/触发机关的联机专属Boss（例如4个方位需要4人同时踩机关触发弱点），制造"单人无法完成，必须组队"的设计动机，避免联机模式只是"人数叠加数值"的空壳。

### 4.（v4新增）联机 × 暧昧剧情如何共存——结构性冲突的解决方案

review4指出的核心冲突：亲密度/荤招小剧场是"玩家与NPC一对一沉浸式关系养成"，天然是单人体验；一旦4人联机同屏，若剧情呈现处理不当，会出现"A玩家的角色正在和师姐互动亲密剧情，同屏被B玩家看到"这种尴尬的产品口碑风险。

**采用组合方案（数据隔离 + 场景隔离，而非单纯依赖某一种）：**

- **场景隔离**：亲密度/荤招小剧场剧情**只在单人局外门派场景触发**（回门派、种灵草、日常剧情），联机只发生在局内秒境战斗场景。战斗场景中不呈现、也不可能触发任何亲密度剧情内容，从场景设计上物理隔离，杜绝"同屏尴尬"问题。
- **数据隔离**：每个玩家在自己的存档里拥有**完全独立的角色养成/亲密度进度**，互不可见、互不影响（类似"动物森友会各玩各的岛"逻辑）。联机战斗中，每个玩家只是"带着自己已解锁的法宝/角色出战形象"参战，不涉及关系剧情的展示或同步，从根本上避免"角色到底属于谁"的解释问题。
- **联机中只共享战斗数值加成**：联机时的角色呈现仅体现战斗层面的形象/技能，完全剥离剧情叙事层，两者互不干扰，"联机"和"养成"两条体验线各自完整，不会互相拖累对方的产品卖点。

## 五、数值曲线示例（v3：删除抽卡保底公式，聚焦局内Build成长曲线）

> v2的抽卡保底公式（`0.006 + (pull_count-70)*0.06` 在88抽即溢出概率100%）已整节删除——买断制不再需要概率保底设计，这类公式也不再有适用场景。

```
# 角色基础伤害成长（指数+线性混合，仍适用于局内Build强度曲线）
base_damage(level) = 10 * (1.08 ^ level) + level * 2

# 秘境怪物血量成长（章节难度曲线，替代原"无限刷图"节奏）
enemy_hp(chapter, wave) = 50 * (1.12 ^ chapter) * (1.05 ^ wave)

# 局内随机词条池权重（三选一，替代抽卡保底逻辑，天然0-1封顶不会溢出）
def weapon_choice_weights(rarity_pool):
    return normalize([w.base_weight * w.rarity_modifier for w in rarity_pool])
    # normalize() 确保权重和为1，从设计上杜绝概率溢出问题

# 联机同屏难度补偿（4人时怪物血量/数量按人数微调，避免太简单或太难）
enemy_hp_coop(base_hp, player_count) = base_hp * (1 + 0.6 * (player_count - 1))
```

> 备注（沿用review2的教训）：所有数值公式在写入正式配置前，必须过一遍边界值测试（例如章节数/波次数的临界值手工验算一次），不能只凭"AI生成的公式看起来合理"就采信——上一版的保底公式溢出就是活生生的反例。

### （v4新增）DLC内容边界原则说明——回应review4"基础版到底包含哪些角色"的疑问

**采用方案A（更符合买断制"一次买断有诚意"的口碑导向）：基础版包含全部核心角色本体**（每人均有Lv1-10基础关系线可玩），DLC**不锁角色本体**，只做以下两类深度内容：
1. **角色关系DLC**：为已有核心角色追加Lv11满级的深度剧情、限定立绘差分、语音包（"加深"而非"解锁角色"）。
2. **新章节/新Boss DLC**：追加战斗内容（新秒境章节、新Boss、新法宝进化分支），可能附带**彩蛋/特典角色**（明确标注为"额外增补角色"，不影响基础版角色本体数量的完整性承诺）。

> 需在宣传物料里明确写清"基础版包含N位核心角色，全部可玩到完整基础关系线"，避免玩家产生"买断制却要另外付费才能玩到全部角色"的缩水观感。若后续团队决定改用方案B（陆续追加新角色的长线运营模式），需要在宣传上提前说明"未来会持续追加角色"预期，二者不可混用或中途切换。

## 七、验证指标与平台建议（吸收review2的"验证成功需要量化标准"意见，适配买断制场景）

买断制单机/联机游戏没有D1/D7留存这类免费游戏指标可直接套用，改用以下适配指标：

- **Steam Demo阶段**：愿望单转化率（Demo试玩→加入愿望单）、Demo完成率（是否玩到Demo结尾）、单局时长是否落在设计的8-15分钟区间。
- **正式发售后**：Steam评测好评率目标（建议≥85%"特别好评"门槛）、主线剧情完成率、DLC购买转化率（基础版玩家中购买至少1个DLC的比例）。
- **联机专项**：4人联机场次占比（验证联机是否被实际使用，而非只是宣传噱头）。

### （v4新增）验证指标初步基准值（回应review4"缺少目标数值"的意见）

以下为初步参考基准，供团队判断"达标/需调整"，实际数值应在Demo上线后结合发行团队的行业数据校准：

| 指标 | 初步参考基准 | 说明 |
|---|---|---|
| Demo试玩→愿望单转化率 | ≥10% | 参考独立游戏Steam Next Fest活动的常见及格线，低于此值需检视Demo前15分钟的核心玩法呈现是否有吸引力 |
| Demo完成率（玩到Demo结尾） | ≥30% | 割草类游戏上手门槛低，完成率过低可能说明难度曲线或前期节奏有问题 |
| 好评率 | ≥85%（"特别好评"档） | 沿用v3已有目标 |
| DLC购买转化率 | 15-25%（基础版玩家中购买至少1个DLC） | 参考同体量买断制独立游戏DLC attach rate的常见区间，具体数值需结合首发DLC定价和内容量再校准 |
| 4人联机场次占比 | ≥20%的总游玩场次 | 用于判断联机是否是"真实被使用的卖点"而非宣传噱头，若显著低于此值需重新评估联机内容投入产出比 |

**平台建议（保留v2结论，版号提示降权为一句话）**：
1. 优先 Steam 首发（买断制+独立游戏定价带成熟，尺度容忍度高，不涉及抽卡审批复杂性）。
2. 联机部分若后续考虑主机平台（Switch/PS），需评估联机网络方案的平台认证要求。
3. 若后续考虑国内平台分发，需评估版号申请路径（买断制无抽卡的产品合规复杂度远低于含抽卡产品，但仍需申请），一句话提示即可，不作为当前阶段的排期瓶颈。
