  • 新增 4人联机设计一节

  • v4新增 解决"联机×暧昧剧情共存"结构冲突 + DLC角色边界说明 + 验证指标基准值

局内/局外玩法结构

局内 · 秒境割草 最高优先级

8-15分钟单局，自动攻击+走位躲Boss，三选一随机词条升级法宝——这是买断制下承接"抽卡不确定性快感"的核心随机奖励钩子，且不涉及付费。章节式内容结构，而非无限刷赛季制。

局外 · 门派养成

弟子历练产出资源，种灵草炼丹。角色通过剧情章节推进解锁（取代抽卡），养成结果反哺局内初始强度。

上瘾/参与感机制（去抽卡化调整）

1. 随机奖励钩子

局内三选一随机词条承接"开箱感"，章节Boss掉落稀有词条书。完全不涉及付费，合规且有效。

2. 沉没成本钩子

赛季通行证 → 章节/DLC发布节奏 + 图鉴/成就全收集系统

3. 社交/传播

排行榜PVP氪金驱动 → 晒养成截图分享（不绑资源奖励）+ 4人组队开黑邀请传播

4. 三层目标

单局(击杀/存活) → 章节目标(Boss通关/图鉴进度) → 长线目标(全成就/DLC剧情线)

多人联机设计 v3新增

  • 联机形式：局内共享同屏联机（4人对抗同一波怪，对标暗黑地牢/元气骑士），局外门派养成各自独立，避免进度绑定摩擦
  • 掉落分配：独立结算，各自获得法宝/资源，减少资源竞争摩擦
  • 联机专属内容：分工站位/触发机关式联机Boss，制造"必须组队"的设计动机
v4新增 · 联机×暧昧剧情共存方案（场景隔离+数据隔离）： 亲密度/荤招剧情只在单人局外门派场景触发，联机战斗场景完全不呈现关系剧情；每个玩家的角色养成/亲密度进度完全独立存档、互不可见（类似"动物森友会各玩各的岛"）；联机中只共享战斗层面的形象/技能，剥离剧情叙事层，从场景和数据两层杜绝"同屏尴尬"风险。

数值曲线示例（已删除抽卡保底公式）

v2的抽卡保底公式在88抽即溢出概率100%，属于数值bug。v3已删除该设计，改用天然0-1封顶的局内随机词条权重系统。
# 角色基础伤害成长
base_damage(level) = 10 * (1.08 ^ level) + level * 2

# 章节难度曲线（替代无限刷图节奏）
enemy_hp(chapter, wave) = 50 * (1.12 ^ chapter) * (1.05 ^ wave)

# 局内随机词条池权重（三选一，天然不会溢出）
def weapon_choice_weights(rarity_pool):
    return normalize([w.base_weight * w.rarity_modifier for w in rarity_pool])

# 联机同屏难度补偿
enemy_hp_coop(base_hp, player_count) = base_hp * (1 + 0.6 * (player_count - 1))

备注：所有公式写入正式配置前必须做边界值验算——上一版保底公式溢出就是活生生的反例。
