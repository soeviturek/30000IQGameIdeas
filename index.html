灵石 · 洞府长青

永久 · 纯数值

每通一局都能带出的硬通货。它只回答一个问题：我的基础战力更强了吗？ 灵石在三位师姐处升级 三维——攻击 / 血量 / 防御 / 暴击 / 移速，无限成长、成本软上限（max:0，指数涨价自然减速）， 每局都拿、每局都有去处。

⚔ 炼器 · 凌霜

攻击 / 剑长 / 攻速 / 暴击（硬顶 50%）。

剑痴冷冽，贴身校剑。

🛡 炼体 · 素心

生命 / 护甲 / 回血 / 初始回血。

温润渡气，传功亲密。

🍃 身法 · 赤芍

移速 / 闪避 / 幸运（掉率·刷新）/ 开局金币。

俏皮爱财，搭手暧昧。

铁律：灵石只买「数字」，永不碰技能。你不会在灵石菜单里看到「雷剑 Lv3」——那是身份与流派的事。灵石就是练基本功。
杜绝：一个菜单同时能买「攻击+5 / 双刀 Lv2 / 分身 Lv2」→ 灵石秒变「万能金币」，以后平衡地狱。

03

战斗 · 20 波破境

8–11 min / run

20 波 = 一局（a game / run），约 8–11 分钟。全自动割草，你只管走位与抉择： 每波清场 → 造化三选一 → 加点 → 下一波。W10 中 boss、W20 妖王，越往后越癫狂。

W1–9 刷怪 · 造化 draft→ W10 中 Boss→ W11–19 精英 · 狂暴→ W20 妖王→ ☯ 渡劫门

🎲 险地阶 · 难度旋钮

出关前自选险地 0…N：怪越强，但收获涨得更快——高难更「划算」也更险，是真抉择。境界焊死你的险地上限。

☯ 渡劫门 · 一局的高潮

清完 W20 → 打该境渡劫战：秒伤门（DPS）+ 躲技能门（预兆雷/AoE）+ 轻 build 门。软失败——没过不掉东西，练强再来。

04

经验 · 这一局的强大

局内 · 清零

击杀掉落经验，只属于这一局。升级 → +10 攻击 / +15 血 / 获得双刀 / 剑气+1； 死亡或出关，全部消失。这是 Brotato / Vampire Survivors 那套即时爽感。

🃏 造化三选一

每波末抽卡组 build：叠攻、点燃、吸血、剑气数、召分身……每局 build 都不一样。

🔗 心法进池

已拜师的心法（如雷剑）进入造化池，用 XP 临时堆叠成「这一局的流派」——永久强度不在这里，在材料。

分工：XP 决定这一局怎么打；灵石决定基础有多硬；材料决定技能有多传奇。三者互不侵占。
05

修为 · 世界越来越大

是等级，不是货币

修为是身份，不是钱包。它只告诉游戏「你到了哪个层次」——像成就，达标就解锁，永不 +属性。 推进它不靠攒进度条，靠打赢该境渡劫。

材料 → 流派：真正改变玩法的，是材料不是钱。为那颗雷晶，再打一把。

06

赌博 · 天命赌坊

灯红酒绿 · 街机

攒够天命，去赌坊拉一把——街机般的灯光、音效与爽感。但奖池里只有皮肤与玩法，没有战力。 赢了很花哨，输了不心疼，这才是能长期玩的赌。

红线：没有 SSR 战力师姐、没有「攻击 +50%」。天命只换 皮肤 / 特效 / 立绘 / 特殊玩法，外加 ≤5% 的小便利（掉率之类，绝不挂修为）。它是收藏，不是氪金变强。

* 设计取舍：奖励太强 → 人人赌博、破坏平衡；太废 → 没人玩。答案是把「强度」抽离出赌局，只赌好看与好玩。Demo 阶段可后做。
